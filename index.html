Home Scales Chord Inversions

A small, static toolkit for practicing scales and chord inversions on a virtual keyboard. Everything runs client-side with plain JavaScript (ES modules) — no build step, no server, so it works directly on GitHub Pages.

  • Scales — pick a root note and major/minor, see the scale highlighted across one octave.
  • Chord Inversions — pick a root note, major/minor, and root/1st/2nd inversion, see the triad voiced and the root note marked.

The keyboard itself is a reusable component (keyboard.js): it just draws an SVG piano for a given MIDI range and lets any page highlight whole keys or drop a circle marker on top of specific keys. The music-theory logic (music-theory.js) is fully separate and DOM-free, so it can be reused or unit-tested on its own.

Built with vanilla JS ES modules. No frameworks, no build step.
